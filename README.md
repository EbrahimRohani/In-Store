# Snapptrip In-Store

Interactive Persian, right-to-left supplier panel for collecting payments for bus tickets issued by agencies and operators.

## Run locally

```sh
npm install
npm run dev
```

Open http://127.0.0.1:5173/ in Chrome.

All tickets, SMS messages, payments, installment eligibility, and settlement amounts in this prototype are simulated. It has no backend, authentication, ticket issuance, or payment integration.
